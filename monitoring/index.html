如何阅读这些指标

TTFT 是引擎观测的首 token 等待时间；TPOT 是引擎请求级平均每输出 token 时间。这里展示最近采集区间的均值，不是 p95，也不等同于客户端端到端时延。

前缀命中率 = 区间命中 token 数 / 查询 token 数。没有查询时显示 N/A。KV 占用 是引擎缓存池使用比例，不是整张 GPU 显存比例。
