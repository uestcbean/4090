# 本地推理观测台

运行 `python monitoring/server.py`，访问 http://127.0.0.1:8090。
默认读取本机 8000 端口 vLLM /metrics，2 秒采样；GPU 通过所在系统 nvidia-smi 读取。
当前实现针对单 GPU、单引擎；多实例指标不能直接套用本聚合方式。

展示运行/等待请求、完成速率、输出吞吐、区间均值 TTFT/请求级 TPOT、prefix token 命中率、KV 池占用及 GPU 状态。
缺少计数、无新样本、计数器重置和服务断线时显示 N/A；不把不存在的指标当成 0。
TTFT/TPOT 是引擎指标，不包含完整客户端网络路径；不是 p95。缓存指标须在实际 vLLM 启动后核对命名和语义。
