# 4090 — 单卡 LLM 推理优化实验室

结合 Stanford CS336，在 Windows + WSL2 / RTX 4090 24GB 上研究多人 LLM 服务的延迟、吞吐、显存和质量权衡。

目标：在固定工作负载、质量要求和延迟 SLO 下提高 goodput，并能用理论、代码和可复现实验解释结果。

**当前状态：路线图已建立；尚未完成模型部署或性能实验，暂无性能提升声明。**

## 工作方式

每个实验依次完成：读理论 → 写预测 → 动手实现 → 验证正确性 → 测量 → 解释结果 → commit → push。
每次学习可拆成 30–60 分钟的小任务；一个实验可以跨多次学习，完成时间取决于实际理解和调试。
先完成当前步骤的验收，再推进依赖它的步骤。失败和负结果保留记录，不填造性能数字。

仓库只保存代码、配置、小型脱敏样本和结果摘要。模型权重、真实用户内容、密钥及大型 trace 不提交。
PLAN 中的 CS336 路径指向原学习工作区；独立克隆本项目不需要相邻课程目录，后续若复用课程代码须注明来源和适用许可。
